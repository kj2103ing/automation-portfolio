DEEP DIVE / CASE 01

바코드 미입력 시 오입고 방지 — 개선 전·후

원본 프로그램에서 실제 재현한 현상을 기준으로, 입고 기동 조건을 어떻게 수정했는지 단계별로 정리했습니다. 아래는 레더 원본 이미지가 아닌 제어 흐름을 설명하기 위한 도식입니다.

01 / PROBLEM

미입력 상태에서 입고 기동

바코드 없이 스캔했을 때 오류 판정 M249가 ON 되었지만, 입고 요청 M240과 입고 시퀀스 M200으로 이어졌습니다. 이전 제품번호 D730이 남아 이전 제품의 위치로 이동하는 문제가 발생했습니다.

02 / ROOT CAUSE

오류 판정과 입고 요청의 연결

원본 M240 SET 조건에 오류 판정 M249가 포함되어 있어, 정상 제품 판정과 오류 판정이 입고 요청 경로에서 구분되지 않았습니다.

03 / SOLUTION

정상 등록 바코드만 허용

M240 기동 조건에서 M249를 제외하고, 등록 바코드 일치 판정 M241~M248만 입고를 요청하도록 수정했습니다. 잔존 제품번호 데이터 초기화도 보완했습니다.

CASE 04 / TROUBLESHOOTING

출고 바코드 불일치 복구

D732 / D140 / M111 / M604 / M603 / M93

01 / 문제 현상

요청 제품과 실제 스캔 제품이 다를 때 기존에는 출고 성공 처리를 하지 않았지만 별도 복구 시퀀스가 없었습니다.

02 / 원인 분석

일치 판정 D732=D140에 의존하는 출고 성공 경로 외에 불일치 제품을 되돌리고 원래 제품을 다시 요청하는 절차가 필요했습니다.

03 / 개선 내용

D732≠D140에서 M111을 SET하고 D310·D311에 제품번호를 보존하며 D740=K13을 표시했습니다. HMI M604 복구 승인 → M603 재입고 → M93 완료 → M606/T50 재출고 경로를 구성했습니다.
