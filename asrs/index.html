CASE 01 / BARCODE

바코드 미입력 시 오입고 방지

개선 전·후 자세히 보기 ↓
문제
바코드 없이 스캔하면 이전 제품번호 D730이 남아 기존 위치로 입고되는 현상.
개선
M240 기동 조건에서 오류 판정 M249 제외, 정상 등록 바코드만 입고 허용 및 데이터 초기화 보완.
검증
동일 조건에서 부저 및 입고 동작이 발생하지 않음을 확인.
CASE 02 / ERROR INDICATION

미등록 바코드 오류 안내

기존 동작
미등록 바코드는 원래 입고되지 않았지만 오류 상태가 명확히 표시되지 않음.
개선
M305 미등록 판정과 HMI 안내 추가, 정상 입고 경로와 오류 판정 분리.
검증
오입고 방지가 아니라 작업자 오류 인지 기능을 개선한 사례.
CASE 03 / RECOVERY

출고 바코드 재스캔

문제
출고 위치에서 바코드 인식 실패 시 재스캔 경로가 없어 PLC 리셋 필요.
개선
M306 → T41 → M97 재스캔 요청, D740=K12 안내, 성공 M99 시 대기 상태 해제.
검증
PLC 전체 리셋 없이 재스캔 후 정상 출고 완료.
CASE 04 / MISMATCH

오출고 복구 및 자동 재출고

문제
요청 제품과 스캔 제품이 불일치할 때 복구 시퀀스 부재.
개선
D732 ≠ D140 → M111 판정. HMI 복구 M604 → 재입고 M603 → 원래 제품 재출고.
검증
복구 버튼 조작 후 잘못 출고된 제품 재입고와 최초 요청 제품 재출고 확인.
CASE 05 / PLC SCAN

복구 후 재출고 타이밍 개선

문제
오출고 제품의 복구 입고 완료 후 원래 요청 제품 재출고가 진행되지 않음.
개선
M606 → T50(K10) → M607/M608 단계로 상태 전환을 분리하고 바코드 데이터 초기화.
검증
PLC 스캔 순서를 고려한 대기·재출고 분기로 정상 출고 확인.
CASE 06 / PNEUMATICS

공압 이상 감지 및 승인 후 재개

문제
공압 밸브 잠금 후 공급이 복귀하면 실린더가 의도치 않게 즉시 동작.
개선
압력 X6 및 T30~T34 감시, M310 이상 판정, HMI 승인·작업별 재개 단계 추가.
검증
공압 공급 정상화만으로 운전하지 않고 복구 조작 후 작업별 재개 확인.
CASE 07 / WIRING

포토인터럽터 역극성 결선 대응

문제
센서 배선 연장 후 최종 단자대에서 +24V/0V가 반대로 연결되어 센서 고장.
조치
배선 원인 추적, 극성 수정, 센서 교체 및 선번·전원 확인 절차 정리.
검증
센서 교체 후 정상 동작과 설비 오류 해제 확인.
기술 자료 출처: 「ASRS_RETRY_포트폴리오_개인화」 발표 자료. 실제 레더 원본 캡처 및 시연 영상은 공개 자료를 선별한 뒤 후속 추가 예정입니다.
DEEP DIVE / CASE 01

바코드 미입력 시 오입고 방지 — 개선 전·후

원본 프로그램에서 실제 재현한 현상을 기준으로, 입고 기동 조건을 어떻게 수정했는지 단계별로 정리했습니다. 아래는 레더 원본 이미지가 아닌 제어 흐름을 설명하기 위한 도식입니다.

01 / PROBLEM

미입력 상태에서 입고 기동

바코드 없이 스캔했을 때 오류 판정 M249가 ON 되었지만, 입고 요청 M240과 입고 시퀀스 M200으로 이어졌습니다. 이전 제품번호 D730이 남아 이전 제품의 위치로 이동하는 문제가 발생했습니다.

02 / ROOT CAUSE

오류 판정과 입고 요청의 연결

원본 M240 SET 조건에 오류 판정 M249가 포함되어 있어, 정상 제품 판정과 오류 판정이 입고 요청 경로에서 구분되지 않았습니다.

03 / SOLUTION

정상 등록 바코드만 허용

M240 기동 조건에서 M249를 제외하고, 등록 바코드 일치 판정 M241~M248만 입고를 요청하도록 수정했습니다. 잔존 제품번호 데이터 초기화도 보완했습니다.

BEFORE / 원본 제어 흐름

오류 판정이 입고 요청으로 연결

바코드 미입력

스캔 요청 발생

M249 ON → M240 SET

오류 판정이 입고 요청에 포함

M200 기동 · D730 잔존

이전 제품번호를 기반으로 위치 이동

AFTER / 개선 제어 흐름

정상 등록 바코드만 입고 요청

바코드 판정

등록 제품 일치 여부 확인

M241~M248 → M240 허용

M249 오류 판정은 입고 요청 조건에서 제외

미입력 시 입고 미진행

기존 제품번호 잔존 방지 초기화 보완

BEFORE / 실제 PLC 레더

개선 전 — 바코드 에러검색 접점

빨간 박스: 바코드 에러검색 M249 접점이 포함된 위치. 이미지를 누르면 크게 볼 수 있습니다.

AFTER / 실제 PLC 레더

개선 후 — 해당 접점 제거

빨간 박스: M240 입고 요청 조건에서 M249 접점을 제외한 위치. 이미지를 누르면 크게 볼 수 있습니다.

실제 검증 결과 · 동일한 바코드 미입력 조건에서 부저가 동작하지 않았고 입고 시퀀스도 진행되지 않았습니다. 원본 대비 오입고 재현 경로가 차단됨을 확인했습니다. 세부 접점 동작 시점은 추가 분석이 필요합니다.
