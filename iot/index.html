05. 센서 계측 및 PLC 제어

프로젝트 발표자료의 센서별 제어 구현(8~13페이지)을 기준으로 입력 신호, PLC 처리 과정, 주요 데이터 주소와 알람 비트를 정리했습니다. MELSEC 아날로그 입력은 Q64AD에서 계측하고, Siemens PLC는 펄스 유량을 계수해 환산합니다.

01. 공통 AD 변환 Function Block · AD_Conv

MELSEC Q64AD의 아날로그 입력값을 실수형으로 변환하고 센서별 스케일을 적용하는 공통 FB입니다. HMI 표시용 정수 PV 변환, 설정값(SV) 초과 판정, 입력값이 K-50 미만일 때의 센서 이상 판정을 하나의 블록으로 구성했습니다.

02. 센서별 공통 FB 적용

MySQL 데이터베이스 설계

센서 이력과 알람 이력을 별도 테이블로 관리하며, 알람 조치 완료 기능을 추가하면서 ACK 컬럼을 확장했습니다.

node_sensor · 센서 데이터 테이블
CREATE TABLE sensor_db.node_sensor (
  no INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
  temp FLOAT(5,2),
  pressure FLOAT(3,2),
  lpm FLOAT(5,2),
  liter FLOAT(5,2),
  ampere FLOAT(3,2),
  ad_val FLOAT(5,2),
  date DATETIME DEFAULT CURRENT_TIMESTAMP
);
alarm_history · 알람 이력 및 ACK 확장
CREATE TABLE sensor_db.alarm_history (
  no INT AUTO_INCREMENT PRIMARY KEY,
  alarm_key VARCHAR(50) NOT NULL,
  alarm_name VARCHAR(50) NOT NULL,
  alarm_event VARCHAR(10) NOT NULL,
  alarm_state BOOLEAN NOT NULL,
  event_time DATETIME NOT NULL
);

ALTER TABLE sensor_db.alarm_history
  ADD COLUMN ack_state TINYINT(1) NOT NULL DEFAULT 0,
  ADD COLUMN ack_time DATETIME NULL;

실제 Function에서 사용한 SQL

조회 기간·표시 개수·센서값·알람 식별자는 Function에서 생성되는 값입니다. 아래 SQL은 가독성을 위해 일부 구문을 축약했으며, 알람 ACK는 후속 복구 이력을 검사한 뒤 갱신합니다.

센서 데이터 저장 · INSERT
INSERT INTO sensor_db.node_sensor
(temp,
  pressure,
  lpm,
  liter,
  ampere,
  ad_val)
VALUES (${temp}, ${pressure}, ${lpm}, ${liter}, ${ampere}, ${ad_val});
기간별 이력 조회 · SELECT
SELECT no,
  date, temp,
  pressure,
  lpm,
  ampere,
  liter,
  ad_val
FROM sensor_db.node_sensor
WHERE date >= NOW() - INTERVAL ${interval}
ORDER BY date DESC
LIMIT ${limit};
알람 발생·복구 기록 · INSERT
INSERT INTO sensor_db.alarm_history
(alarm_key, alarm_name, alarm_event, alarm_state, event_time)
VALUES ('${key}', '${name}', '${event}', ${state}, NOW());
알람 조치 완료 · UPDATE
UPDATE sensor_db.alarm_history
SET ack_state = 1, ack_time = NOW()
WHERE no = ${no} AND alarm_state = 1 AND ack_state = 0
  AND EXISTS (/* 동일 알람의 후속 복구 이력 확인 */);
센서 이력 전체 삭제 · DELETE
DELETE FROM sensor_db.node_sensor;
ALTER TABLE sensor_db.node_sensor AUTO_INCREMENT = 1;
