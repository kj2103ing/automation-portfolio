04. 주요 구현 기능

실시간 센서 모니터링

온도·압력·유속·전류·유량의 PV/SV, 설비 연결 상태, 전력·동작시간을 표시하고 실시간 트렌드를 제공합니다.

MySQL 이력조회

센서 데이터를 MySQL에 저장하고 조회 범위·표시 개수를 선택해 차트와 표로 확인합니다.

알람 및 상태 표시

센서 초과·고장 및 통신 상태를 감시하고 알람 발생·복구 이력과 조치 상태를 확인합니다.

원격 모니터링

웹에서 MELSEC·Siemens 밸브 ON/OFF와 상태를 확인하고 센서 설정값, DB 저장 및 화면 갱신 주기를 관리합니다.

05. 센서 계측 및 PLC 제어

온도·압력·유속·유량·전류 센서의 신호를 PLC에서 취득하고, 아날로그 스케일링 또는 펄스 카운팅을 통해 실제 계측값으로 변환합니다. 자동/수동 제어와 인터록, 솔레노이드 밸브 출력은 모니터링 시스템의 현장 제어 기반입니다.

MELSEC Q Series

Q64AD 아날로그 입력으로 온도·압력·유속·전류 센서를 계측하고 설정값 비교 및 센서 이상 알람을 처리합니다.

Siemens S7-1200

유량 센서 펄스 입력을 계수하고 환산하여 유량값을 표시하며 설비 제어 데이터와 연동합니다.

06. X-SCADA 통합 센서 대시보드

현장 PLC와 연동한 센서 계측값(PV), 실시간 트렌드, 설비 조작 및 MySQL 데이터 관리를 하나의 X-SCADA 화면에 구성했습니다.

6종 센서 실시간 표시

온도(℃), 압력(MPa), 유속(LPM), 유량(L), 전류(A), 원격 계측 AD값을 표시하고 각 센서의 변화 추이를 트렌드 차트로 확인합니다.

설비 조작 및 초기화

대시보드 우측 상단 원형 버튼은 MELSEC PLC 솔레노이드 밸브, 하단 원형 버튼은 Siemens PLC 솔레노이드 밸브 조작용으로 구분했습니다. 옆의 초기화 버튼은 별도 초기화 기능입니다.

03 · 알람 감지 및 이력 처리

알람 발생·복구 변화를 감지해 alarm_history에 기록하고, 복구 조건을 확인한 후 조치 완료를 저장합니다.

MySQL 데이터베이스 설계

센서 이력과 알람 이력을 별도 테이블로 관리하며, 알람 조치 완료 기능을 추가하면서 ACK 컬럼을 확장했습니다.

node_sensor · 센서 데이터 테이블
CREATE TABLE sensor_db.node_sensor (\n  no INT NOT NULL AUTO_INCREMENT PRIMARY KEY,\n  temp FLOAT(5,2), pressure FLOAT(3,2),\n  lpm FLOAT(5,2), liter FLOAT(5,2),\n  ampere FLOAT(3,2), ad_val FLOAT(5,2),\n  date DATETIME DEFAULT CURRENT_TIMESTAMP\n);
alarm_history · 알람 이력 및 ACK 확장
CREATE TABLE sensor_db.alarm_history (\n  no INT AUTO_INCREMENT PRIMARY KEY,\n  alarm_key VARCHAR(50) NOT NULL,\n  alarm_name VARCHAR(50) NOT NULL,\n  alarm_event VARCHAR(10) NOT NULL,\n  alarm_state BOOLEAN NOT NULL,\n  event_time DATETIME NOT NULL\n);\n\nALTER TABLE sensor_db.alarm_history\n  ADD COLUMN ack_state TINYINT(1) NOT NULL DEFAULT 0,\n  ADD COLUMN ack_time DATETIME NULL;

실제 Function에서 사용한 SQL

조회 기간·표시 개수·센서값·알람 식별자는 Function에서 생성되는 값입니다. 아래 SQL은 가독성을 위해 일부 구문을 축약했으며, 알람 ACK는 후속 복구 이력을 검사한 뒤 갱신합니다.

센서 데이터 저장 · INSERT
INSERT INTO sensor_db.node_sensor\n(temp, pressure, lpm, liter, ampere, ad_val)\nVALUES (${temp}, ${pressure}, ${lpm}, ${liter}, ${ampere}, ${ad_val});
기간별 이력 조회 · SELECT
SELECT no, date, temp, pressure, lpm, ampere, liter, ad_val\nFROM sensor_db.node_sensor\nWHERE date >= NOW() - INTERVAL ${interval}\nORDER BY date DESC\nLIMIT ${limit};
알람 발생·복구 기록 · INSERT
INSERT INTO sensor_db.alarm_history\n(alarm_key, alarm_name, alarm_event, alarm_state, event_time)\nVALUES ('${key}', '${name}', '${event}', ${state}, NOW());
알람 조치 완료 · UPDATE
UPDATE sensor_db.alarm_history\nSET ack_state = 1, ack_time = NOW()\nWHERE no = ${no} AND alarm_state = 1 AND ack_state = 0\n  AND EXISTS (/* 동일 알람의 후속 복구 이력 확인 */);
센서 이력 전체 삭제 · DELETE
DELETE FROM sensor_db.node_sensor;\nALTER TABLE sensor_db.node_sensor AUTO_INCREMENT = 1;
