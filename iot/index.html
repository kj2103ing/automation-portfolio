PROJECT 02 / INDUSTRIAL IoT

PLC 기반 IoT 통합센서
모니터링 시스템

MELSEC 및 Siemens PLC의 센서 데이터를 Node-RED로 통합 수집하고, Dashboard 2.0에서 실시간 상태와 이력을 시각화한 산업용 모니터링 프로젝트입니다.

MELSEC PLCSiemens PLCNode-REDDashboard 2.0MySQL

01. 프로젝트 개요

서로 다른 제조사의 PLC에서 취득한 센서 데이터를 하나의 화면으로 통합하고, 실시간 모니터링뿐 아니라 데이터 저장·조회, 이상 상태 감시까지 구현했습니다.

수집 데이터

온도 · 압력 · 유속(LPM) · 전류 · 유량 · 원격 AD값

핵심 기능

실시간 상태 표시 · 트렌드 차트 · 이력조회 · 이상 알람 · 통신 상태 감시

02. 시스템 구성

MELSEC PLC
Siemens PLC
→
MC Protocol / S7
Node-RED
→
Dashboard 2.0
실시간 시각화
↔
MySQL
이력 데이터

Node-RED에서 PLC 통신 데이터와 상태 정보를 처리하여 화면에 전달하고, MySQL에 축적된 데이터를 기간별로 조회합니다.

03. 주요 구현 기능

실시간 센서 모니터링

센서별 측정값과 설정값(SV)을 표시하고, 게이지 및 트렌드 차트로 변화 추이를 확인합니다.

MySQL 이력조회

측정 데이터를 데이터베이스에 저장하고, 선택한 조회 기간의 데이터를 차트와 테이블로 확인합니다.

알람 및 상태 표시

센서 초과·고장 등 비정상 상태를 감지하고, 정상 운전·통신 오류·설비 이상 상태를 구분합니다.

원격 모니터링

Dashboard 접속과 브라우저 알림을 활용하여 원격 환경에서도 설비 상태를 확인할 수 있도록 구성했습니다.

04. 구현 화면 및 기술 상세

실제 Dashboard 캡처, Node-RED 플로우, PLC 디바이스 매핑, MySQL 조회 화면을 추가하여 구현 근거를 단계별로 정리할 예정입니다.

현재 페이지는 프로젝트 기본 구조입니다. 이후 실제 구현 화면과 문제 해결 사례를 확인하며 상세 내용을 보강합니다.
